# Analogue Clock Projects — Conventions & Style Guide

## Project Structure
Each clock lives in its own subfolder with exactly **3 files**:
```
clockName/
  clockName.html
  style.css
  script.js
```

## Font
Always use **Limelight** from Google Fonts — both `--font-display` and `--font-body`.
```html
<link href="https://fonts.googleapis.com/css2?family=Limelight&display=swap" rel="stylesheet" />
```

## HTML Structure Pattern
```html
<div class="clock-header">
  <h1 class="clock-title">...</h1>
</div>
<div class="clock">
  <div class="c1">           <!-- bezel ring -->
    <div class="c2">         <!-- dial face -->
      <div class="numbers">  <!-- 12 spans with --i: 0..11 -->
      <div class="pin"><div class="inner"></div></div>
      <div id="hr"></div>
      <div id="min"></div>
      <div id="sec"></div>
    </div>
  </div>
</div>
```
Always **3 hands** (hr, min, sec) — each a different color. Always visualize time passing.

## CSS Color Palette System
- One palette is **active** at the top of `:root` (clearly marked).
- All other palettes are **commented out** below it in the same `:root` block.
- To switch: comment out the active block, uncomment the desired one.
- **Derived tokens** (everything referencing `var(--X)`) live below all palettes — never change those.

### Required palette variables (define these per palette):
```css
--background      /* page bg / dial face */
--outerFace       /* lightest bezel / shell color */
--outerFace-mid   /* mid tone */
--outerFace-deep  /* deepest / shadow tone */
--edge            /* accent / highlight ring color */
--text            /* title */
--text-soft       /* subtitle */
--text-muted      /* numbers */
--light           /* pure highlight white */
--shadow          /* darkest shadow base */
--color-second-hand
--color-hour-hand
--color-minute-hand
```

## JavaScript Pattern
Clean, minimal — calculate degrees, apply transforms, `setInterval(fn, 1000)`.
```js
const degSeconds = (seconds * 360) / 60;
const degMinutes = ((minutes + seconds / 60) * 360) / 60;
const degHours   = ((hours + minutes / 60 + seconds / 3600) * 360) / 12;
```

## Visual Design Principles
- **Simple yet impressive** — bold shapes, clean structure, rich shading.
- Use `conic-gradient` on the bezel ring (`c1`) for metallic shimmer.
- Use `radial-gradient` overlays on the outer case (`.clock`) for 3D depth / light hotspot.
- Use `box-shadow` in layers: inset for dial depth, drop for lift, glow for accent.
- Use `linear-gradient` overlay on hands (`background-image` over `background-color`) for metallic bevel.
- Hands should have a subtle glow matching their color.
- Numbers: Limelight, `color-mix` text-shadow, rotated via `--i` CSS variable trick.
- Tick marks (where used): positioned radially with `rotate(calc(var(--j)*30deg)) translateY(Xpx)` — NO counter-rotation needed.

## Clock Geometry Reference (goldMedal / standard round)
- `.clock`: 450×450, `border-radius: 50%`, `transform: scale(1.15)`
- `.c1` (bezel): 370×370, `margin: 40px 0 0 40px`
- `.c2` (dial): 300×300, `margin: 35px auto 0` — center is at (150, 150)
- Numbers: `translateY(-105px)`, font-size 22px
- Tick marks: `translateY(-133px)`, cardinal ticks `translateY(-133px)` but taller
- Pin: 44×44, `margin: 128px 0 0 128px`
- `#hr`:  w=22, h=90,  `margin: 70px 0 0 139px`,  `transform-origin: 11px 80px`
- `#min`: w=12, h=120, `margin: 16px 0 0 144px`,  `transform-origin: 6px 134px`
- `#sec`: w=6,  h=175, `margin: 100px 0 0 147px`, `transform-origin: 3px 45px`

## goldMedal SVG Clock — Special Notes
goldMedal is SVG-based (not CSS div-based). Different conventions apply:
- **Color variables**: `--bg`, `--face-outer`, `--accent`, `--hand`, `--text-clock`, `--title`
- **SVG fills** are driven entirely by CSS (`.face-base`, `.face-accent`, `.hand-hr rect`, etc.)
- **Arc mechanism**: `<mask id="hour-arc">` with a rotating wedge (`g.arc-hand`) reveals the accent arc progressively as hours pass (like a progress ring)
- **Numbers/ticks**: generated by JS — cardinals (3,6,9,12) as `<text>`, others as `<line>` tick marks with `f-glow` filter
- **Rotation formula for tick lines**: `rotate(30 * hour)` — NOT `rotate(-90 + 30*hour)` (that's for translate-based text positioning)
- **3 hands all auto-run**: `setInterval(tick, 1000)` — no anime.js, no controls
